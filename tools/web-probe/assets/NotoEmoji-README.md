# Browser emoji fallback

Unmodified NotoEmoji.ttf from Rustable's existing licensed asset.
Source: https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoemoji
SIL OFL 1.1: see NotoEmoji-OFL.txt.

Size: 1,982,596 bytes. SHA-256:
de6c18832938afc99caf132b39d6a30a19bac7f2e812e28db2535b4608d27551

Loaded from the same origin only when emoji input/preedit is observed, separately
from CJK and WASM. The font stays shared across panes until page close. It uses
monochrome outline glyphs; this is not native color-emoji parity or a guarantee
of coverage for every emoji sequence.
