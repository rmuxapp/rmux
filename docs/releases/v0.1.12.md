# rmux 0.1.12 — preview

This release polishes search, tab renaming, and project context.

## Everyday navigation

- File-preview search finds literal text in reading order.
- Tab renaming shows the name limit and keeps overlong drafts available for correction. Closing another tab preserves the draft and focus.
- Text fields preserve modified shortcuts and reset horizontal scrolling correctly when text becomes shorter.

## Project context

- Local terminals can explicitly look up pull requests using an existing authenticated GitHub CLI. The sidebar shows the result and opens its link; pending lookups can be canceled from the command palette.
- Port summaries retain the last explicit scan and identify partial snapshots.
- New terminal histories use one atomic initial write, reducing startup disk work.
- The browser demo shares the desktop branch/directory row and keeps sample directories consistent across tabs, splits, and sample `pwd` output.

## Downloads and validation

GitHub builds the signed and notarized macOS Apple Silicon DMG and ZIP, Linux
x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle.
The [browser demo](https://rmux.app) runs bundled sample sessions, without shell or server access.

Focused tests and desktop compilation passed during development. Browser checks
covered tab-renaming focus and close behavior. Native visual review and Windows
runtime validation remain pending.

Use rmux alongside VS Code with its built-in external-terminal shortcut:
[setup guide](https://rmux.app/vscode/).
