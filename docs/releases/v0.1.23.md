# rmux 0.1.23

Show terminal task status in the workspace sidebar consistently.

- Include program status reports from all applications, including reports without an application name, instead of requiring the exact name `Claude`.
- Summarize status across all live tabs and panes, including inactive tabs. Show terminal progress when no program status is available.
- Keep workspace status visible in compact-sidebar mode. Prioritize blocked and error states, then ongoing work; include percentages and a count of additional reports.
- Exclude exited terminals and remove badges when reports clear.
- Includes the Apple Icon Composer macOS icon update from 0.1.22.

Addresses [#17](https://github.com/rmuxapp/rmux/issues/17).

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Validation: four focused workspace-status regression tests, the desktop debug build, and live RPC smoke checks passed. Tests cover unnamed and differently named applications, status priority, multiple reports, progress, and removal of exited or cleared status. Native Windows runtime validation remains deferred.
