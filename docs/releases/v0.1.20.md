# rmux 0.1.20

Fix Cmd+K stopping unexpectedly and make shell exits close consistently after startup.

- Cmd+K no longer gets stuck after ignored terminal title, working-directory, or oversized control messages. Clearing still waits safely for incomplete messages to finish or cancel.
- Interactive shells that have run for at least two seconds now close on exit regardless of their final status, including Ctrl+D after a failed command. Successful exits close immediately.
- Failures within the first two seconds and explicitly launched commands stay open for inspection. Ctrl+D inside a running application continues to reach that application normally.
- Tab closure waits for buffered output, cleans up empty panes and windows, and leaves unrelated sessions running.

Addresses the reproducible Cmd+K failure reported in [#12](https://github.com/rmuxapp/rmux/issues/12).

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Native Windows runtime validation remains deferred.
