# rmux 0.1.21

Improve link hover feedback, tab zoom, and Claude Code workspace status.

- Hold Cmd on macOS or Ctrl on Linux/Windows while hovering a link to underline its visible text, including wrapped URLs and OSC 8 labels. The destination appears at the bottom of the terminal pane instead of in a popup.
- Double-click a terminal tab to toggle pane zoom within the window. Rename remains available from the tab context menu.
- Local shell integration launches Claude Code with session-local hooks for working, approval, completion, and error states in tabs and the workspace sidebar, plus completion and approval notifications. Existing Claude settings files and user shell aliases/functions are preserved.
- Use `rmuxctl claude` explicitly when needed, or set `RMUX_CLAUDE_INTEGRATION=0` to opt out. Print mode, redirected output, and explicit `--settings` arguments pass through unchanged.
- Includes the Cmd+K fix shipped in 0.1.20, with its regression checks reverified.

Addresses [#13](https://github.com/rmuxapp/rmux/issues/13), [#14](https://github.com/rmuxapp/rmux/issues/14), and [#15](https://github.com/rmuxapp/rmux/issues/15).
