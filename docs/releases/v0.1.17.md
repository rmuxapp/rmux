# rmux 0.1.17

Polish terminal shortcuts, shell exits, menus, and macOS installation.

- Cmd+K now clears terminal scrollback on macOS, preserving the current screen and running shell.
- Successful shell exits, including Ctrl+D at an empty prompt, close their tabs after buffered output drains. Empty panes, workspaces, and windows are cleaned up; failed sessions and directly launched command output remain available for inspection.
- File, Edit, and View commands are grouped into submenus, with existing actions and shortcuts preserved.
- The macOS installer places rmux on the left and Applications on the right.

Addresses GitHub issues #5, #6, #8, and #9.

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

The desktop/CLI debug build, focused terminal tests, and native RPC smoke checks passed, including Ctrl+D closure and last-tab cleanup. Compressed DMG layout metadata was verified. Native visual review remains pending; Windows runtime validation remains deferred.
