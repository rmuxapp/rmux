# rmux 0.1.16

Customize the terminal cursor and simplify the workspace layout from Settings.

- Enable cursor blinking alongside the existing Application, Block, Bar, and Underline styles. Typing and focus restore a visible cursor.
- Show tab, split, zoom, and workspace-add controls only on hover, with space reserved so tabs do not shift.
- Hide the in-window top workspace bar. macOS window buttons retain a drag area when the sidebar is also closed.
- Enable a compact sidebar with single-row workspace names, icons, pins, and unread badges, hiding descriptions and other detail rows.

All new toggles default to off. Changes apply immediately and support Save and Revert.

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

The debug build and 40 preference tests passed. Native visual review remains pending; Windows runtime validation remains deferred.
