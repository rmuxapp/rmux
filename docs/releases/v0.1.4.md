# rmux 0.1.4 — preview

A quieter command palette and more reliable navigation between terminals.

- Search highlights matching words in command and workspace results.
- Cancellation commands appear only when the relevant operation is running.
- Back and Forward commands revisit terminals across tabs, panes and workspaces. Find them in the menu or command palette, or assign your own shortcuts.
- Automation can navigate that same history with `rmuxctl focus-back --window ID` and `focus-forward --window ID`. Window activation is opt-in with `--activate`.

Cmd+P opens the palette. Cmd+[ / ] cycles panes, and Cmd+Shift+[ / ] switches tabs; these shortcuts are unchanged from 0.1.3.

Packages include a signed and notarized macOS Apple Silicon DMG and Sparkle ZIP, Linux x86-64 tar.gz, and unsigned Windows x86-64 ZIP. Linux requires Ubuntu 24.04-compatible libraries. Linux/Windows native UI and cross-platform performance acceptance remain in progress. The experimental browser is not enabled in these builds.

On macOS, use **rmux → Check for Updates…**. Other platforms update manually.
