# rmux 0.1.10 — preview

This release improves command search, terminal file links, and Settings, and adds
experimental per-terminal shell history restore.

## Everyday polish

- The command palette shows your position in filtered results in both the app and browser demo.
- Clearing a palette search skips unnecessary scoring and sorting.
- Terminal file links support local `~/` paths, quoted filenames with line and column suffixes, and compiler locations such as `src/main.rs(12,3)`.
- Disabled Settings buttons now behave consistently with keyboard and mouse input. Settings distinguishes terminal scrollback from saved shell command history.

## Optional shell history restore

Enable `shell_history_directory` in Settings JSON and restart to save separate
command histories for local zsh and non-login Bash terminals. Saved sessions
restore those commands for shell history navigation without executing them.
Writes run in the background, and restored terminals get independent copies.

This feature is **off by default and experimental**. History files are private
but unencrypted. Old files are not automatically cleaned up, and individual
history-entry deletion is not synchronized. Missing history files produce an
error rather than silently losing references. See the
[configuration and limitations](https://github.com/rmuxapp/rmux/blob/v0.1.10/docs/guide/settings.md#restore-per-terminal-command-history-experimental).

## Downloads and validation

GitHub builds the signed and notarized macOS Apple Silicon DMG and ZIP, Linux
x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle.
The [browser demo](https://rmux.app) uses bundled sample sessions.
Use the [VS Code setup guide](https://rmux.app/vscode/) to open or reuse your
project workspace through the standard external-terminal shortcut.

Focused tests cover history storage, shell import and shutdown, file-link
resolution, and palette search. Browser interaction checks cover the palette
footer. Native visual review and Windows runtime validation remain pending.
