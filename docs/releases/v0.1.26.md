# rmux 0.1.26

Clearer text hover feedback and better-spaced context menus.

- Show the I-beam cursor over visible terminal text, including wide characters, while blank cells and terminal padding retain the arrow. Actionable links keep the hand pointer; terminal selection gestures are unchanged.
- Show the I-beam cursor in editable text fields.
- Give workspace and terminal-tab context menus more room around their headings, consistent row line heights, and straight section dividers separated from rounded selection backgrounds.
- Adjust menu scrolling limits to accommodate the taller headers in small windows. Shared browser-demo menus receive the same spacing improvements.

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Validation: desktop check and debug build passed; both context menus were visually checked in an isolated native preview. Native Windows runtime validation remains deferred.
