# rmux 0.1.24

A dedicated, searchable Settings window with clearer controls and compact feedback.

- Open Settings in its own resizable window, with category icons, an organized sidebar, and setting descriptions.
- Search across all settings using local sparse-vector ranking, related terms, prefixes, and typo matching. Search runs locally without a remote service or model download.
- Discover JSON-only options alongside editable settings, with direct access to the configuration file.
- Improve keyboard navigation, toggle controls, and the save/revert footer. Keep configuration details and status messages inside their associated rows or tooltips.
- Show notifications as compact floating toasts without shifting the layout. Successful actions display a checkmark; save confirmations dismiss automatically, with the full message available to copy.
- Clean up native build warnings from deprecated xattr types and browser-only helpers.

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Validation: 14 focused Settings tests, the desktop/CLI debug build, release metadata checks, and native Settings visual checks passed. The live-shell RPC smoke check passed once but showed intermittent input/exit failures on repeat runs; the installed prior release also reproduced the shell-exit failure. Native Windows runtime validation remains deferred.
