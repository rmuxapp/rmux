# rmux 0.1.18

Make macOS Cmd+K clear output above the current input line as well as scrollback.

- Cmd+K now performs Clear to Start, preserving the current input and running shell, including wrapped input lines.
- Clearing waits for incomplete terminal escape sequences to finish and leaves alternate-screen applications alone.
- Edit → Clear to Start exposes the action in the menu. Clear Scrollback remains available separately; Linux and Windows Ctrl+K remains available to the shell.
- Ctrl+D retains the v0.1.17 behavior: successful shell exits close their tabs; failed sessions and explicitly launched commands remain available for inspection.

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Validation: desktop debug build, terminal tests, focused clear tests, and the original successful-shell-exit regression passed. Native Windows runtime validation remains deferred.
