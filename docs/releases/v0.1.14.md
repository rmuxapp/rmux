# rmux 0.1.14

Themes now apply to the entire rmux window, including the sidebar, tabs, command palette, menus and Settings.

- All seven built-in themes are supported, including Solarized Dark and Solarized Light. Imported themes and explicit color overrides also style the surrounding interface.
- Theme changes apply live across windows, with matching selection, border and accent colors and readable text in light and dark themes.
- Settings, Notifications and Memory replace one another consistently and preserve the terminal return-focus target.
- An invalid external-editor setting no longer prevents startup. rmux disables that optional editor and displays repair guidance without changing the configuration file.
- Browser-demo palette search uses the same field-aware matching as the native app.

## Downloads

GitHub builds the signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle.

Focused theme/contrast and editor-recovery tests passed. Native review covered Catppuccin Latte, light palette input, and live switching to Nord. Shared WASM compilation passed. Windows runtime validation remains deferred.
