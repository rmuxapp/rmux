# rmux 0.1.6 — preview

This release improves everyday navigation, settings recovery and working with
an editor alongside rmux.

- A cleaner command palette with searchable shortcuts, a clear-search button,
  context-aware group actions and more reliable dismissal and focus recovery.
- More consistent workspace selection, tab close buttons, toolbar hints and
  rename controls. Narrow windows keep more space available for the terminal.
- Terminal Find clearly indicates when there are no matches. Tab pickers stay
  current as tabs open, move and close.
- Settings show unsaved appearance changes, let you revert them, and offer
  **Undo Last Settings Save** while preserving unrelated configuration edits.
- Open or reuse a named workspace from an editor with `rmuxctl open-workspace`.
  Bind configured background commands to shortcuts, including switching back
  to your editor without opening another terminal.
- Open local `file://` terminal links in your configured editor. Recognized
  remote sessions do not route these links to local files.
- Clearer CLI connection errors, steadier diagnostic panels, fewer duplicate
  group notifications and less sidebar work during rendering.
- Help and feedback links are easier to find. macOS update prompts include
  release notes and a link to the full release.

The website demo shares the palette, navigation and interface improvements.
It continues to use sample sessions rather than a real shell; local editor
launching and other desktop integrations are not available in the browser.

Packages target macOS Apple Silicon, Linux x86-64 and Windows x86-64. The Windows
package is unsigned; Linux requires Ubuntu 24.04-compatible libraries. Native
Linux/Windows UI and cross-platform performance acceptance remain in progress.
Experimental browser windows are not enabled in these release builds.

On macOS, use **rmux → Check for Updates…**. Other platforms update manually.
