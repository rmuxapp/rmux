# rmux 0.1.5 — preview

This release focuses on terminal responsiveness, workspace reliability, and a
cleaner command palette.

- The palette has clearer spacing, shortcut badges and empty states. Abbreviated
  searches highlight the letters that matched, including Unicode names and
  terminal directories. Cmd+P opens it; Escape or Close dismisses it.
- Catppuccin Mocha and Latte join the terminal themes. Settings also lets you
  adjust cursor and selection opacity.
- Busy terminal output no longer makes selection wait on the parser. Paste and
  pointer handling use bounded queues, and hidden terminal rendering releases
  unused resources.
- Session recovery reports checkpoint failures instead of silently losing the
  opportunity to save. Normal macOS quit requests use the app's confirmation and
  terminal cleanup path.
- Markdown previews support web links and keyboard link navigation. Captured
  code blocks scroll instead of stopping after a few displayed lines.
- Shell integration uses fish's native prompt markers when available and handles
  PowerShell command status more reliably.
- Automation can follow terminal and workspace events with `rmuxctl read-events
  --follow`, including filters and resumable cursors. CLI completion and JSON
  output from `pipe-pane` have also improved.

Workspace movement and merging retain running shells. Additional live checks
cover process continuity, tab order, selected tabs, and unread messages across
window transfers.

The website demo now shares substantially more of rmux's layout, input and
terminal rendering code, using the pinned Ghostty engine compiled to WASM.
It still runs sample sessions, not a real shell.

Packages include a signed and notarized macOS Apple Silicon DMG and Sparkle ZIP,
a Linux x86-64 tar.gz, and an unsigned Windows x86-64 ZIP. Linux requires Ubuntu
24.04-compatible libraries. Linux/Windows native UI and cross-platform performance
acceptance remain in progress. Experimental browser windows are not enabled in
these release builds.

On macOS, use **rmux → Check for Updates…**. Other platforms update manually.
