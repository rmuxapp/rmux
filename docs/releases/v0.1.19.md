# rmux 0.1.19

Restore your workspaces automatically when reopening rmux.

- Normal launches now save and restore windows, workspace names and groups, splits, tabs, selection, and working directories by default.
- Quitting retains all open windows. Closing the final window retains that window for reopening, including through the native macOS close button and confirmation dialog.
- Restored terminals start fresh shells; running processes and scrollback are not resumed. Explicitly closed workspaces and terminals remain closed.
- Recovery defaults to a config.session.json file beside your settings. Alternate config profiles stay isolated. Set restore_session to false to disable automatic recovery, or use session_file to choose a custom file.
- Existing recovery locks, atomic saves, and protection for corrupt or unrestorable files remain in place. Explicit layout, session, directory, and command launches stay isolated from automatic recovery.

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Validation: desktop debug build, seven recovery-related tests, multi-window session restore and crash-recovery smoke tests, default recovery and opt-out checks, and native macOS close/reopen checks passed. Native Windows runtime validation remains deferred.
