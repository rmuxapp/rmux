# rmux 0.1.11 — preview

This release improves file previews, context menus, and terminal tab search.

## File previews

- Wide Markdown tables scroll horizontally with their headings aligned. Preview shortcuts also scroll selected tables and code blocks.
- Markdown heading links work within a document and between local Markdown files. Back and Forward restore your reading position.
- Switching between Markdown and source view keeps your source position. Opening a selected preview row in an editor passes its source line when the editor configuration supports it.
- File links and preview history now route through the active palette correctly.

## Menus and navigation

- Workspace, tab, and link menus identify their target. Close confirmations name the affected workspace or terminal and explain their scope.
- Context-menu navigation respects modifiers, avoiding accidental activation from modified keys.
- The terminal tab chooser shows filtered counts, highlighted matches, and your position in the results. The browser demo also supports paging through tab results.

## Downloads and validation

GitHub builds the signed and notarized macOS Apple Silicon DMG and ZIP, Linux
x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle.
The [browser demo](https://rmux.app) uses bundled sample sessions.

Focused tests cover Markdown links and parsing, preview history and source
positions, and menu navigation. Desktop compilation and browser interaction
checks passed during development. Native visual review and Windows runtime
validation remain pending.
