# rmux 0.1.22

Update the macOS app icon to Apple's Icon Composer format.

- Let macOS control the icon's outer shape and sizing instead of baking rounded corners and padding into the artwork.
- Preserve rmux's violet panes and terminal prompt, with default, dark, clear, and tinted appearances.
- Include Apple's generated fallback icon assets for older macOS versions alongside the layered catalog.
- Verify icon source and generated asset hashes during packaging, and install the compiler-generated icon lookup keys before signing.

Addresses [#16](https://github.com/rmuxapp/rmux/issues/16).

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Validation: Apple's compiler accepted the icon source; rendered appearance variants and small sizes were inspected. Generated catalog sizes and appearance records, the debug bundle's icon resources and lookup keys, and its code signature passed validation. Older-macOS runtime and live Dock/Finder appearance checks remain unverified. Native Windows runtime validation remains deferred.
