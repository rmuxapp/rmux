# rmux 0.1.9 — preview

This release polishes command search and keyboard focus in the app and browser demo.

## Command palette

- Search native workspaces by project path, group, or description, including workspaces in other windows. The current workspace is marked in results.
- Workspace shortcut hints follow your configured bindings.
- The browser palette follows the native command order, with New Workspace and New Tab near the top. Page navigation accounts for two-line workspace results.
- Shell line-start, line-end, and delete-to-start actions share bindings and command names across the native app and demo.

## Keyboard focus

- Canceling the terminal tab chooser returns focus to where you opened it, including Find. Choosing a tab focuses that terminal.
- Opening the chooser from its toolbar no longer steals focus before saving the return target.

## Availability

GitHub builds the signed and notarized macOS Apple Silicon DMG and ZIP, Linux
x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle.
The [browser demo](https://rmux.app) uses bundled sample sessions, not real shells.
The [VS Code guide](https://rmux.app/vscode/) explains how to open and reuse a
project workspace with VS Code’s external-terminal command.

Focused compilation and browser interaction checks cover the polish changes.
Native visual review and native Windows runtime validation remain pending.
Per-terminal persistent shell history is still under development and is not enabled.
