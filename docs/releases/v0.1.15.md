# rmux 0.1.15

Workspace and terminal tab colors now fill the row or tab, making projects easier to tell apart.

- Set individual terminal colors from the tab menu using a preset or custom hex color. Colors survive session restore and tab moves.
- Workspace and group colors fill the sidebar row, with readable text in light and dark themes.
- Tabs share the available width, with a simpler underline for the active tab and cleaner spacing in narrow panes.

## Downloads

Signed and notarized macOS Apple Silicon DMG and ZIP, Linux x86-64 tarball, and Windows x86-64 ZIP. macOS updates use Sparkle. All release builds run on GitHub.

Native visual review, focused color persistence tests and shared WASM compilation passed. Windows runtime validation remains deferred.
